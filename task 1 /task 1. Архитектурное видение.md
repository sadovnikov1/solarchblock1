1. Задача
Кому помогает: Компания Diamond Universe (отдел продаж, логистики, лаборатория)
В чем проблема: Пандемия сделала невозможным личные встречи с покупателями. Бизнес теряет выручку, потому что традиционные офлайн-аукционы встали.
Какое решение требуется: Организовать онлайн-продажу алмазов, обеспечив покупателям дистанционную оценку качества камней, не уступающую личному присутствию.
Почему важно: Без этого рынок сбыта сокращается, компания теряет долю рынка.

2.2 Текущее состояние (AS-IS) — как сейчас
**Процессы**:
- Отбор алмазов. Эксперты в офисе отбирают камни для продажи в ИС "Алмазы".
- Оценка качества. Покупатели лично приезжают, смотрят камни, оценивают вне какой-либо ИС.
- Аукцион офлайн. Покупатели посещают физический Аукцион.
- Логистика. Перевозка покупателям после аукциона. ИС "Логистика".
- Оцифровка камней не производится.
- Облачные сервисы	не используются.
Ключевой GAP: Нет возможности удаленной оценки → нет онлайн-продаж.

2.3 Целевое состояние
Оцифровка камней.	Лаборатория создает цифровой двойник камня - 3D-модель, фото, параметры.
Публикация данных.	Данные загружаются в облако или ИС «Аукцион».
Оценка покупателем.	Покупатель изучает камни онлайн через веб-портал.
Аукцион.	Онлайн-торги через ИС «Аукцион» (новая версия).
Отгрузка.	Автоматическая отправка победителям через ИС «Логистика».

2.4 Ограничения 
- Временные.	Первый аукцион через 2 месяца. Нельзя дорабатывать существующие ИС к этому сроку.
- Технические.	ИС «Алмазы», «Аукцион», «Логистика», «Бухгалтерия» — нельзя трогать в ближайшие 2 месяца.
- Организационные.	ИС «Лаборатория» - внешняя, управляется подрядчиком. Облачный провайдер — внешний.
- Бизнес.	Данные об алмазах конфиденциальны. Нужны защищенные каналы передачи
- Финансовые.	Бюджет на промежуточное решение минимальный (Excel + облако)
Важно: В целевом решении многие ограничения снимутся, можно будет дорабатывать ИС.

3.2 Промежуточное решение (Interim) — на 2 месяца
Суть: Минимум доработок, максимум Excel и ручного труда.

Процесс:
- Отбор алмазов » из ИС «Алмазы» выгружаем в Excel список камней;
- Перевозка в лабораторию → ИС «Логистика» (уже работает, новых интеграций не надо);
- Оцифровка → ИС «Лаборатория» делает описание камней → выгружает в Excel по шаблону;
- Публикация данных → Excel-файлы загружаются в частное облако (новый провайдер);
- Проведение аукциона → ИС «Аукцион» работает офлайн, но ставки принимаются по email/телефону/конфколлу (ручной ввод);
- Отправка камней → ИС «Логистика» (уже работает);

Что нужно сделать:
- Заключить договор с провайдером частного облака;
- Подготовить Excel-шаблоны для лаборатории и аукциона;
- Настроить ручной процесс сбора ставок;
- Обучить сотрудников;

Риски: Ручной труд, ошибки в Excel, нет автоматизации, зависимость от сотрудников.
